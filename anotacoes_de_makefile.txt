CC define o compilador a ser usado

CFLAGS é a lista de flags a serem passadas para o comando de compilação

DEPS é a lista de arquivos de cabeçalho


Gerar um arquivo objeto (.o) precisa do arquivo .c e dos seus cabeçalhos
%.o: %.c $(DEPS)
    $(CC) -c -o $@ $< $(CFLAGS)

OBJ é a lista de arquivos objetos (gerados pelos arquivos .c)

$@ = esquerda de :
$^ = direita de :
$< = primeiro item da lista
