ORGANIZACAO DO CODIGO

INCLUDE
    settings: structs e referencia principais variaveis.
    inicializations: referencia modelos prontos de structs
    O resto referencia as funcoes de seus respectivos arquivo-fonte.

OBJECTS
    Arquivos objetos de todos os arquivos de source.

SOURCE 
    allmain: gerencia mudança de niveis e informações do jogador.
    main: onde rocorrem as fases

    DEFINITIONS
        inicializations: contem os dados especificos de cada fase referente às entidades e externos a elas
        sprites: desenho de entidades e das telas do jogo 
        variable_definition: define as principais variaveis do programa
    
    FUNCTIONS
        cutscenes: algoritmos para "animações"
        player_functions: funções relacionadas ao jogador
        enemy_functions: funções relacionadas aos inimigos
        general_functions: funções relacionadas a variáveis externas às entidades
        auxiliary: outras funções


--
CRIAR UMA NOVA FASE REQUER:
1. Em 'sprites.c':
    - Add nova tela de mudança de nivel, antes de 'boss fight'
    - Add nova tela de level up, antes de 'vitoria'
    - Add novo modelo de aviao do player
    - Add novo modelo de aviao de inimigo

2. Em 'inicializations.c':
    - Add novas configuracoes de player, inimigo e fase
